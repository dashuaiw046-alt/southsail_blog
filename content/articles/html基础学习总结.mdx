# HTML基础学习总结

## 一、学习背景

最近为了学习网络安全方向，先补了一下 Web 前端基础，其中 HTML 是 Web 页面最基础的一部分。

在学习过程中，我没有单纯去背标签，而是尝试自己写一个简单的 demo 页面，通过不断修改代码来理解 HTML 的结构和语法。

这次练习主要是为了：

- 熟悉 HTML 基础语法
- 理解网页结构组成
- 为后续学习 JavaScript、DOM、XSS 等 Web 安全内容打基础

------

# 二、HTML 基础结构

一个完整的 HTML 页面主要由：

```html
<!DOCTYPE html>

<html>

<head>

</head>

<body>

</body>

</html>
```

组成。

其中：

## 1. `<!DOCTYPE html>`

用于告诉浏览器：

> 当前页面使用的是 HTML5 标准。

------

## 2. `<html>`

表示整个网页的根节点。

所有网页内容基本都需要写在：

```html
<html>

</html>
```

里面。

------

## 3. `<head>`

存放网页的一些信息。

例如：

```html
<title>
```

用于设置浏览器标签页名称。

同时这里还可以放：

- CSS
- JavaScript
- 页面编码

------

## 4. `<body>`

真正显示给用户看的内容。

例如：

- 文字
- 图片
- 表格
- 表单

等。

------

# 三、HTML 常用标签学习

## 1. 标题标签

HTML 提供：

```html
<h1>
<h2>
<h3>
...
<h6>
```

其中：

- h1 最大
- h6 最小

例如：

```html
<h1>
southsail Web Demo
</h1>
```

------

## 2. 段落标签

```html
<p>

内容

</p>
```

用于表示一段文字。

------

## 3. 换行和分割线

换行：

```html
<br>
```

水平分割线：

```html
<hr>
```

------

# 四、CSS 基础学习

HTML 负责网页结构。

CSS 负责网页样式。

学习了三种 CSS 使用方式：

## 1. 行内样式

例如：

```html
<h1 style="color:red">
```

直接写在标签里面。

------

## 2. class选择器

CSS：

```css
.demo1{

}
```

HTML：

```html
<p class="demo1">
```

特点：

一个 class 可以被多个标签使用。

------

## 3. id选择器

CSS：

```css
#demo2{

}
```

HTML：

```html
<p id="demo2">
```

特点：

id 一般用于唯一元素。

------

# 五、链接和图片

## 超链接

使用：

```html
<a>
```

例如：

```html
<a href="网址">
博客
</a>
```

其中：

```html
target="_blank"
```

可以让链接新窗口打开。

------

## 图片

使用：

```html
<img>
```

例如：

```html
<img src="图片路径">
```

同时可以添加：

```html
alt
```

作为图片说明。

------

# 六、列表

HTML 有两种列表。

## 1. 无序列表

```html
<ul>

<li>

</li>

</ul>
```

显示：

- 内容1
- 内容2

------

## 2. 有序列表

```html
<ol>

<li>

</li>

</ol>
```

显示：

1. 内容1
2. 内容2

------

# 七、表格

学习了：

```html
<table>
<tr>
<th>
<td>
```

结构：

```text
table
 |
 tr
 |
 th / td
```

其中：

- table 表示整个表格
- tr 表示一行
- th 表示表头
- td 表示普通数据

------

# 八、表单学习（重点）

表单是 Web 安全里面非常重要的一部分。

主要学习：

```html
<form>
<input>
<button>
```

## 输入框

普通文本：

```html
<input type="text">
```

密码：

```html
<input type="password">
```

------

## 单选框

radio：

```html
<input type="radio">
```

例如：

男 / 女选择。

需要配合：

```html
name
```

保证只能选择一个。

------

## 复选框

checkbox：

```html
<input type="checkbox">
```

可以实现多选。

------

## 提交按钮

```html
<button type="submit">
提交
</button>
```

用于提交表单数据。

------

# 九、学习过程中遇到的问题

第一次写 demo 时出现了一些问题：

例如：

## 1. 标签拼写错误

把：

```html
<form>
```

写成：

```html
<from>
```

说明 HTML 标签需要严格按照规范。

------

## 2. 对 input 类型理解不足

一开始误以为：

```html
button
```

可以实现男女选择。

后来理解：

- button = 按钮
- radio = 单选框
- checkbox = 复选框

不同标签负责不同功能。

------

# 十、和网络安全的联系

HTML 看似只是写网页，但其实和 Web 安全关系很大。

例如：

用户输入：

```html
<script>alert(1)</script>
```

如果网站没有正确处理：

可能导致：

## XSS（跨站脚本攻击）

基本流程：

```
用户输入

↓

服务器处理

↓

网页显示

↓

浏览器解析HTML/JS

↓

代码执行
```

所以：

HTML 中的：

- input
- form
- 页面输出

都是以后学习 Web 漏洞的重要基础。
