# XXE：从 XML 到外部实体

当解析器允许外部实体时，攻击者可能读取本地文件或访问内网资源。

## XML 里真正危险的是什么

XML 本身不是问题。问题在于解析器是否展开 DTD 和外部实体。

```xml title="payload.xml"
<?xml version="1.0"?>
<!DOCTYPE foo [
  <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<root>&xxe;</root>
```

如果解析器展开 `&xxe;`，文件内容就可能进入后续处理流程。

## 防御

在解析器配置中禁用：

- DTD
- 外部实体
- 外部 schema

并优先使用成熟的安全默认配置。

## 检查表

| 配置 | 建议 |
| --- | --- |
| 外部实体 | 关闭 |
| DTD | 关闭 |
| 网络访问 | 解析器不应主动出网 |
| 输入格式 | 能不用 XML 就不用 XML |

## 和注入类问题的共同点

SQL 注入、文件上传和 XXE 都有同一条主线：

**不要把不可信输入当成可执行结构的一部分。**
